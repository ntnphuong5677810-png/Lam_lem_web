# LẤM LEM — Landing Page Xưởng Gốm Thủ Công

Landing page một trang (one-page) giới thiệu xưởng gốm thủ công **Lấm Lem Ceramics Studio**: bán sản phẩm gốm làm tay và nhận đăng ký lớp trải nghiệm làm gốm cuối tuần.

- **Đối tượng:** người trẻ thích đồ gốm thủ công để dùng/trang trí/làm quà + người muốn học làm gốm cuối tuần.
- **Thiết kế:** font Fraunces + Be Vietnam Pro; bảng màu kem #FAF5EE, đất nung #B4552D, nâu đậm #3B2A20; có bản thiết kế Figma tương ứng.
